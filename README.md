# السائق الجزائري

تطبيق أندرويد مستقل يعرض الوثائق المطلوبة عند الحاجز الأمني في الجزائر، والمخالفات بموادها وإجراءاتها. يعمل بدون إنترنت.

بعد كل تحديث يبني GitHub ملف APK تلقائياً، وتجده في قسم **Releases** باسم `algerian-driver.apk`.

## فاحص الفواتير
الوحدة `invoice/` تطبيق ثانٍ مستقل: `invoice-checker.apk`. يقرأ صورة الفاتورة داخل الهاتف دون إنترنت (ML Kit) ويملأ الخانات تلقائياً.
